# Find the Difference

## Problem Statement

You are given two strings `s` and `t`. String `t` is generated by random shuffling string `s` and then adding one more letter at a random position.

Return the **letter that was added** to `t`.

The overall runtime complexity must be strictly bounded by:

```text
O(n)
```

*(where n is the length of string s)*

---

## Examples

### Example 1

**Input**

```java
s = "abcd"
t = "abcde"
```

**Output**

```java
"e"
```

**Explanation**

`'e'` is the letter that was added to `t`.

---

### Example 2

**Input**

```java
s = ""
t = "y"
```

**Output**

```java
"y"
```

---

## Brute Force Approach

Count all character frequencies in `s` using a map or sorted list, then compare them against `t` to locate the character with the mismatched count.

### Steps

1. Convert both strings to character arrays: `s.toCharArray()` and `t.toCharArray()`.
2. Sort both arrays globally using a sorting routine.
3. Iterate through the arrays up to the length of `s`. Compare elements at index `i`.
4. The first position where `s[i] != t[i]` holds the injected letter. If the loop completes without a mismatch, the injected letter sits at the final index of `t`.

### Complexity

```text
Time Complexity: O(n * log(n)) // due to character array sorting overhead
Space Complexity: O(n) to store the character array copies
```

Global array sorting introduces an unnecessary log-linear overhead. We can achieve a highly optimized **single-pass solution with zero extra space** by utilizing bitwise operators.

---

# Optimal Approach: Bitwise XOR Cancellation

## Key Idea

We can isolate the inserted character in **O(n) time and O(1) space** by taking advantage of the properties of the bitwise **XOR (`^`)** operator.

The XOR operator follows three core mathematical identities:
1. `x ^ 0 = x` (An element XORed with 0 stays unchanged)
2. `x ^ x = 0` (An element XORed with itself cancels out to 0)
3. `x ^ y = y ^ x` (The operation is commutative and associative, meaning order does not matter)

Because of these properties, if we XOR every character from string `s` and string `t` together, **every character that appears in both strings will pair up and cancel each other out to `0`**. 

The only character value left standing at the end of the entire loop will be the unique, extra letter added to `t`.

---

## Visual Understanding

Suppose `s = "abcd"` and `t = "ceabd"`:

Initialize an accumulator variable `charXor = 0`. Let's accumulate XOR operations across all characters sequentially:

```text
charXor = 0 ^ 'a' ^ 'b' ^ 'c' ^ 'd' ^ 'c' ^ 'e' ^ 'a' ^ 'b' ^ 'd'
```

Since order does not affect the outcome, we can visually re-group the characters:
```text
charXor = ('a' ^ 'a') ^ ('b' ^ 'b') ^ ('c' ^ 'c') ^ ('d' ^ 'd') ^ 'e'
charXor = 0 ^ 0 ^ 0 ^ 0 ^ 'e'
charXor = 'e'
```

The duplicate values wipe each other out entirely, leaving the character `'e'` isolated.

## Partition Variables

Let:

```java
char charXor = 0;
```

---

### Border Elements

The XOR gate operates on raw character byte codes directly, automatically shielding the calculation path against type overflows or special symbol boundaries.

---

## Correct Partition Condition

The linear pass processes characters across both strings to accumulate the single-character remainder footprint:

```java
for (int i = 0; i < s.length(); i++) {
    charXor ^= s.charAt(i);
}
for (int i = 0; i < t.length(); i++) {
    charXor ^= t.charAt(i);
}
return (char) charXor;
```

---

## Java Solution

```java
class Solution {

    public char findTheDifference(String s, String t) {
        int charXor = 0;

        // Step 1: XOR all characters of string s
        for (int i = 0; i < s.length(); i++) {
            charXor ^= s.charAt(i);
        }

        // Step 2: XOR all characters of string t
        for (int i = 0; i < t.length(); i++) {
            charXor ^= t.charAt(i);
        }

        // The remaining value is the unique, added character code
        return (char) charXor;
    }
}
```

### Complexity Metrics

---

## Key Insight

Leveraging the self-canceling property of the XOR logic gate reduces a frequency distribution tracking problem into a constant-space bitwise accumulation pass.

```text
Time  : O(n) linear execution pass
Space : O(1) absolute constant extra memory
```
