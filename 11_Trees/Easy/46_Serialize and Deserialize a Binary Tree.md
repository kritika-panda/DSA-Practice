 # Serialize and Deserialize a Binary Tree - Java

 

## Problem Statement

 

Serialization is the process of converting a data structure or object into a sequence of bits so that it can be stored in a file or memory buffer, or transmitted across a network connection link to be reconstructed later in the same or another computer environment.

 

Design an algorithm to serialize and deserialize a binary tree. There is no restriction on how your serialization/deserialization algorithm should work. You just need to ensure that a binary tree can be serialized to a string and this string can be deserialized to the original tree structure.

 

---

 

## Example

 

### Input

 

```text

        1

       / \

      2   3

         / \

        4   5

```

 

### Serialized String Output

```text

"1,2,#,#,3,4,#,#,5,#,#"

```

*(where `#` represents a `null` node marker)*

 

---

 

# Approach

 

## Idea

 

To capture the definitive shape of a general binary tree without structural ambiguity, we must record both the values of the nodes and the explicit locations of empty (`null`) child branches.

 

We can achieve this using a **Pre-order Traversal (Root → Left → Right)** scheme:

- **Serialization**: We traverse the tree recursively. For each node, we append its value followed by a delimiter (e.g., `,`). If we encounter a `null` pointer, we append a special marker like `#`.

- **Deserialization**: We split the serialized string by the delimiter into a linear sequence or queue. We then reconstruct the tree recursively in the exact same pre-order sequence. Each call polls the next token: if it matches `#`, we return `null`; otherwise, we instantiate a new node with the value and recursively attach its left and right subtrees.

 

---

 

## Algorithm

 

### Serialization

1. If the current node is `null`, return the string marker `"#,"`.

2. Convert the current node's value to a string and append a comma delimiter.

3. Recursively call serialization on the left child and append it.

4. Recursively call serialization on the right child and append it.

5. Return the accumulated string.

 

### Deserialization

1. Split the input string by commas `,` and insert all components into a FIFO `Queue<String>`.

2. Create a recursive helper function `deserializeHelper(queue)`:

   - Poll the next token from the queue.

   - If the token equals `"#"`, return `null`.

   - Otherwise, convert the token to an integer and create a new `TreeNode`.

   - Recursively build the left child: `node.left = deserializeHelper(queue)`.

   - Recursively build the right child: `node.right = deserializeHelper(queue)`.

   - Return the constructed node.

3. Return the root node generated by the helper.

## Java Solution

 

```java

import java.util.*;

 

public class Codec {

    static class TreeNode {

        int val;

        TreeNode left;

        TreeNode right;

        TreeNode(int val) {

            this.val = val;

        }

    }

 

    // Encodes a tree to a single string.

    public String serialize(TreeNode root) {

        StringBuilder sb = new StringBuilder();

        serializeHelper(root, sb);

        return sb.toString();

    }

 

    private void serializeHelper(TreeNode node, StringBuilder sb) {

        if (node == null) {

            sb.append("#,");

            return;

        }

       

        // Root -> Left -> Right (Pre-order Traversal)

        sb.append(node.val).append(",");

        serializeHelper(node.left, sb);

        serializeHelper(node.right, sb);

    }

 

    // Decodes your encoded data to tree.

    public TreeNode deserialize(String data) {

        if (data == null || data.isEmpty()) {

            return null;

        }

       

        // Split the data and populate a queue to maintain sequential order

        String[] tokens = data.split(",");

        Queue<String> queue = new LinkedList<>(Arrays.asList(tokens));

       

        return deserializeHelper(queue);

    }

 

    private TreeNode deserializeHelper(Queue<String> queue) {

        if (queue.isEmpty()) {

            return null;

        }

       

        String currentToken = queue.poll();

        if (currentToken.equals("#")) {

            return null;

        }

 

        // Reconstruct nodes in Pre-order sequence

        TreeNode root = new TreeNode(Integer.parseInt(currentToken));

        root.left = deserializeHelper(queue);

        root.right = deserializeHelper(queue);

 

        return root;

    }

 

    // Helper method to print inorder traversal for structural validation

    public static void printInorder(TreeNode node) {

        if (node == null) return;

        printInorder(node.left);

        System.out.print(node.val + " ");

        printInorder(node.right);

    }

 

    public static void main(String[] args) {

        Codec codec = new Codec();

       

        TreeNode root = new TreeNode(1);

        root.left = new TreeNode(2);

        root.right = new TreeNode(3);

        root.right.left = new TreeNode(4);

        root.right.right = new TreeNode(5);

 

        String serializedString = codec.serialize(root);

        System.out.println("Serialized: " + serializedString);

 

        TreeNode deserializedRoot = codec.deserialize(serializedString);

        System.out.print("Deserialized Tree (Inorder): ");

        printInorder(deserializedRoot);

        System.out.println();

    }

}

```

## Dry Run

 

Using the example string `"1,2,#,#,3,4,#,#,5,#,#"`:

 

### Step 1

- `queue.poll()` reads `"1"`. Not a `#`.

- Node `1` is created. Recursion invokes left child boundary.

 

### Step 2 (Left child of Node 1)

- `queue.poll()` reads `"2"`. Not a `#`.

- Node `2` is created. Recursion invokes left child boundary.

 

### Step 3 (Left child of Node 2)

- `queue.poll()` reads `"#"` -> Returns `null`. `2.left = null`.

 

### Step 4 (Right child of Node 2)

- `queue.poll()` reads `"#"` -> Returns `null`. `2.right = null`.

- Node `2` completes and returns up to `1.left`.

 

### Step 5 (Right child of Node 1)

- `queue.poll()` reads `"3"`. Not a `#`.

- Node `3` is created. Recursion invokes left child boundary.

 

### Step 6 (Left child of Node 3)

- `queue.poll()` reads `"4"`. Not a `#`.

- Node `4` is created. Its left and right children next read `"#"` and `"#"` from the queue, returning `null`.

- Node `4` completes and connects to `3.left`.

 

### Step 7 (Right child of Node 3)

- `queue.poll()` reads `"5"`. Not a `#`.

- Node `5` is created. Its left and right children next read `"#"` and `"#"` from the queue, returning `null`.

- Node `5` completes and connects to `3.right`.

- Node `3` completes and connects to `1.right`. Tree is fully restored.

## Time Complexity

 

```text

O(N)

```

Where `N` is the total number of nodes in the binary tree. During serialization, every node and `null` pointer is visited exactly once. During deserialization, every split token string is peeled off the queue in constant `O(1)` runtime operations.

 

---

 

## Space Complexity

 

```text

O(N)

```

The serialized string buffers and split structural arrays hold data proportional to `N`. Furthermore, the call stack frames track up to the maximum height `O(H)`, which generalizes to `O(N)` storage overhead under completely skewed trees.

## Interview Follow-Up Questions

 

### Q1. Can this problem be solved using a Level-Order Traversal (BFS) approach?

Yes. You can serialize the tree level-by-level using a standard `Queue` loop, printing `null` children as `#`. For deserialization, use a queue to store constructed parent nodes. As you step through the flat data string array tokens, assign the left and right values sequentially to the head queue element, and push non-null children back into the queue.

 

### Q2. How can you optimize the serialized output size?

If memory string footprints are highly constrained, you can switch from ASCII text format to binary byte streams using standard serialization encoding tools like Protocol Buffers, or pack integers together into compact byte matrices instead of using commas and text string representations.
